# A股选股台

免费数据驱动的沪深A股研究工具，提供 Windows 便携版与手机自适应网页界面。

## Windows 下载使用

在本仓库 **Releases** 下载 `ashare-screener-windows-0.2.0.zip`，完整解压到可写目录，双击 `Start-Screener.cmd`。包中包含 Node.js，无需注册数据账号或单独安装 Node。启动器会打印实际本机地址，已有软件占用端口时选择空闲端口。

再次双击会复用本目录的服务。需要关闭服务时先在页面停止运行中的任务，再双击 `Stop-Screener.cmd`。关闭浏览器不会自动关闭后台服务。不要从压缩包内部直接启动。

程序只监听本机回环地址，数据保存在解压目录。不同人的包各自独立，发布包包含空白记录。自选与命名策略属于浏览器存储，换浏览器或本机地址前请在“本机备份”导出。

## 功能

- 短线和波段筛选，逐项条件解释，临界观察与完整名单导出。
- 自选股、盘中观察与本机偏好导入预览。
- 稳健历史趋势、扫描留档、同条件新增/保留/跌出比较。
- 历史技术信号回测、固定规则每日复盘、模拟持仓与账本保护。
- 新实例启用模拟后，在首个有信号的复盘结束时建立自己的3/5/10交易日计划。已登记信号不会倒填到过去。

固定短线持有3根、波段5根有效日线，包含入场日，每边成本10bp、滑点5bp。普通筛选页的参数和固定模拟计划分开管理。

## 手机网页

同一套界面支持手机尺寸，提供触控导航、可横向查看的表格和网页应用清单。部署到具备后端与HTTPS的独立服务后，安卓浏览器可使用安装/添加到桌面，iPhone可从Safari的分享菜单添加到主屏幕。

当前仓库提供网页源码，尚未托管公开运行服务。GitHub仓库和GitHub Pages均不会替你运行本项目的Node后端。手机中的127.0.0.1指向手机本身，不能访问另一台电脑上的本机地址。移动尺寸经过桌面浏览器检查，安卓/iPhone实机和HTTPS安装待后续部署验证。

## 从源码运行

需要 Node.js 24 和 npm。

```sh
npm ci
npm test
npm run build
node launcher.cjs --no-browser
```

打开启动器打印的地址。Windows也可在构建后双击 `Start-Screener.cmd`，源码包会使用已安装的Node。

启动器显式设置 `SCREENER_PORTABLE=1`，备份和趋势档案也保存在实例目录。后端仍仅允许本机访问，外网部署前需要另行配置监听、身份鉴别、HTTPS、持久存储与任务资源隔离。请勿把含个人数据的实例目录直接公开。

## 文件位置

|目录|用途|
|---|---|
|`.data`|行情、扫描结果、模拟账本和独立阶段计划|
|`.local/backups`|经过校验的账本及报告备份|
|`.local/archives`|趋势档案|
|`.runtime`|启动状态、临时文件及日志|

以上目录不进入源码仓库或发布包。升级前保留整个旧目录，并在页面导出偏好及账本。不要用旧文件覆盖正在运行的新实例。

## 数据与研究边界

日线使用新浪财经，东方财富备用。BaoStock为可选数据源，需要自行配置 `SCREENER_PYTHON` 和 `.runtime/python-deps`，Windows便携包未内置Python。免费接口可能延迟、限流或历史不足，软件保留来源日期、限次重试及冷却。日线失败会单列，不自动伪造股票或收益。

股票池按当前条件筛选后限量扫描，历史研究存在选择偏差。单条模拟收益不等于资金账户收益，未完整模拟流动性、最低佣金、资金占用等因素。程序提供研究与模拟功能。

Node.js及前端依赖许可见Windows包内的 `THIRD-PARTY-NOTICES.txt`。
